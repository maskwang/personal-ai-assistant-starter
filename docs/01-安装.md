# 01 · 安装

## 前置依赖

| 依赖 | 检查命令 | 说明 |
| :--- | :--- | :--- |
| Git | `git --version` | 版本管理与备份 |
| curl | `curl --version` | 钉钉推送 |
| Obsidian | — | 打开 `vault/` 目录 |
| Node.js | `node -v` | 仅接 MCP 时需要（提供 `npx`） |

macOS 上 `git` 与 `curl` 通常已自带；Node.js 建议用 `brew install node` 安装。

## 安装

```bash
cd my-assistant
./install.sh
```

脚本做四件事（可重复执行，不会覆盖你填好的配置）：

1. 检查依赖；
2. 给 `scripts/*.sh` 加执行权限；
3. 生成 `scripts/config.env`（权限 600），并把 `VAULT_ROOT` 自动填成你的 vault 绝对路径；
4. 初始化 Git 仓库并完成首次提交。

## 验证

```bash
./scripts/notify.sh test      # 需要先填好 webhook，见 docs/03
git -C vault status           # 应显示干净的仓库或未跟踪的新笔记
```

## 打开 vault

Obsidian → **Open folder as vault** → 选择 `my-assistant/vault`。

建议再做两件事：

1. 设置 → 文件与链接 → 新建笔记默认位置设为 `01-收件箱(Inbox)`，避免散落根目录；
2. 安装 **Templater** 插件，模板目录指向 `04-资源(Resources)/Templates`（模板里用了 `tp.date.now` 语法）。

## 备份到远端（建议）

个人知识库请用**私有仓库**：

```bash
cd vault
git remote add origin git@github.com:<你的账号>/<私有仓库>.git
git push -u origin main
```

> 若 `scripts/config.env` 和 vault 在同一个仓库里，注意它已被 `.gitignore` 排除；如果 vault 是独立仓库，请把 `config.env` 放在 vault 之外。
