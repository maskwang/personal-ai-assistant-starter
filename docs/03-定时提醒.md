# 03 · 定时提醒（钉钉）

目标：到点把手机会推你一下，告诉你「现在该做什么」。把作息从**意志力问题**变成**环境问题**。

## 1. 建机器人

钉钉群 → 群设置 → 智能群助手 → 添加机器人 → **自定义（Webhook）** → 安全设置选「自定义关键词」，填一个词（例如 `行动`）。

复制 Webhook 地址（形如 `https://oapi.dingtalk.com/robot/send?access_token=...`）。

## 2. 填配置

```bash
cp scripts/config.env.example scripts/config.env
chmod 600 scripts/config.env
```

编辑 `scripts/config.env`：

```bash
DINGTALK_WEBHOOK="https://oapi.dingtalk.com/robot/send?access_token=你的token"
DINGTALK_KEYWORD="行动"
VAULT_ROOT="/ABSOLUTE/PATH/TO/my-assistant/vault"
```

> 关键词必须出现在消息里，否则钉钉会拒收（errcode 310000）。`notify.sh` 已做兜底：消息不含关键词时自动补前缀。

## 3. 自测

```bash
./scripts/notify.sh test
```

群里收到消息即通。看 `scripts/notify.log` 有 `errcode:0` 也算通。

## 4. 改时间与文案

- **时间点** → `scripts/dispatch.sh` 里的 `case "$NOW" in` 分支（24 小时制 `HHMM`）；
- **文案** → `scripts/notify.sh` 里对应的 `CONTENT="..."`。

写文案的经验：**具体到动作，别写口号**。对比「注意休息」和「前 15 分钟闭目养神：耳机戴好，手机放回口袋」——后者才有人执行。

## 5. 开启定时

```bash
./scripts/install-launchd.sh com.你的名字.assistant.notify
```

安装的是**每分钟唤醒一次**的 LaunchAgent，具体是否推送由 `dispatch.sh` 判断。这样即使 Mac 中途睡眠，醒来后一分钟内也会补上。

想改成「只在固定时间点触发」，用 `config/com.example.assistant.notify.plist`（注意：睡眠时那一刻会直接跳过，不补跑）。

## 6. 验证与停用

```bash
launchctl list | grep assistant        # 应能看到你的 label
tail -f scripts/launchd.err           # 看有没有报错
./scripts/notify.sh morning            # 手动触发一条，确认文案符合预期
```

停用：

```bash
launchctl unload ~/Library/LaunchAgents/com.你的名字.assistant.notify.plist
rm ~/Library/LaunchAgents/com.你的名字.assistant.notify.plist
```

## 7. 每天自动快照（可选）

把 `auto-commit.sh` 也挂上（推荐 23:50），知识库就永远有版本可回滚：

```
50 23 * * * /bin/bash /ABSOLUTE/PATH/TO/my-assistant/scripts/auto-commit.sh
```

cron 与 launchd 二选一即可；Linux 上用 cron 更省事。
