# 99 · 常见坑（这一页最值钱）

都是真踩过的，按踩到的顺序记。每一条都附了症状，方便你搜到。

## 1. obsidian-mcp 的参数变了，旧写法会告警并失效

**症状**：启动日志里出现 `[V1_POSITIONAL_CONFIG_DEPRECATED]`，提示 `Detected: /path -> vaults`。

**原因**：v2 起要用 `serve --vault 名字=路径`，旧的「位置参数」形式将被移除。

**改法**：

```json
"args": ["-y", "obsidian-mcp", "serve", "--vault", "myvault=/ABSOLUTE/PATH/TO/vault"]
```

## 2. MCP 的编辑工具是「整篇替换」

**症状**：Obsidian 里刚手动加的一段话，被 AI 一次性覆盖没了。

**原因**：很多工具的 `replace` 语义是替换整篇内容，而不是增量改一处。

**改法**：先读（拿到 etag）→ 改 → 带着 etag 再写。冲突时写入会被拒绝，而不是静默覆盖。重要的写入前先 `git status` 看一眼。

## 3. 钉钉拒收：关键词没命中

**症状**：返回 `errcode: 310000`，`keywords not in content`。

**原因**：机器人安全设置选了「自定义关键词」，消息里必须原样包含该词。

**改法**：`notify.sh` 已做兜底（消息不含关键词时自动加前缀）；如果你改过安全设置（例如换成签名或 IP 白名单），记得同步改脚本。

## 4. launchd 不继承你 shell 里的 PATH

**症状**：手动跑脚本没问题，launchd 定时跑就报 `command not found`。

**原因**：LaunchAgent 只有最简环境，没有 `.zshrc` 里 export 的 PATH。

**改法**：脚本里显式 `export PATH=...`，或用绝对路径调用命令（`notify.sh` 里已处理 curl 的这种情况）。

## 5. Mac 睡眠会吃掉定时点

**症状**：07:00 的提醒那天没来。

**原因**：`StartCalendarInterval` 在机器睡眠时不会补跑。

**改法**：改用「每分钟唤醒 + 脚本内判断 HHMM」的模式（`scripts/install-launchd.sh` 就是这么做的），醒来后一分钟内补上。脚本里用 `"0700"|"0701"` 双分钟匹配，防止某一分钟被系统漏掉。

## 6. 时区不是本地时间

**症状**：提醒时间整体偏移了几小时。

**原因**：容器或云端 runner 的时区与本地不同；`date +%H%M` 取的是系统时区。

**改法**：本地 LaunchAgent 一般没这个问题；如果在容器里跑，显式设置 `TZ=Asia/Shanghai`。

## 7. 凭据被提交进 Git

**症状**：`git log -p` 里能翻到 webhook token。

**原因**：`config.env` 没进 `.gitignore`，或者一开始就把它写进了笔记。

**改法**：`.gitignore` 里排除 `scripts/config.env`（本套件已含）。一旦推送到远端就必须**撤销 token**（钉钉里重置 webhook），删历史只是补刀。

## 8. 个人知识库误设为公开仓库

**症状**：健康数据、家庭信息、财务结构全部可被检索。

**原因**：建仓库时手快点成了 public。

**改法**：永远 private。推送前用 `git remote -v` 确认目标仓库，敏感数据（体检报告图片等）想清楚再入库。

## 9. 自动提交制造了空提交噪音

**症状**：每天的提交记录都是「无变化」。

**改法**：提交前先判 `git status --porcelain` 是否为空（`auto-commit.sh` 已处理），不要无脑 `git commit --allow-empty`。

## 10. 两套系统双写漂移

**症状**：日历里改了时间，vault 里还是旧的；任务在两边各有一半。

**改法**：明确分层——**执行层**（日历 / 任务 App）管一线任务与日程，**复盘层**（vault）管规划、复盘、画像。执行不进 vault，避免两份真相。

## 11. 健康与财务档案空着，AI 只能给泛泛建议

**症状**：问「我该怎么规划」，助理答得像通用文章。

**原因**：`03-领域(Areas)/个人/` 下的画像档案是空的，助理没有可依据的事实。

**改法**：先花 20 分钟填三份档案：基础画像（家庭结构、年龄、职业）、财务状况（收支、资产、负债、风险偏好）、目标与价值观（长期目标、红线）。填完之后，同样的提问质量会完全不同。

## 12. 提醒文案写成了口号

**症状**：推送每天都在发，但你从来不看。

**原因**：文案是「注意休息」「保持专注」这类无法执行的话。

**改法**：写成具体动作 + 时间窗：「前 15 分钟闭目养神，耳机戴好，手机放回口袋」。提醒的价值在于**替你决策**，不在于替你打气。
