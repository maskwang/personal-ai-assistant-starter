# 你的知识库

用 Obsidian 打开这个目录（**Open folder as vault**）。目录按 PARA 组织：

| 目录 | 放什么 | 判断标准 |
| :--- | :--- | :--- |
| `00-日记/` | 每日记录与复盘 | 按日期 |
| `01-收件箱(Inbox)/` | 临时灵感、待处理片段 | 还没想好归属 |
| `02-项目(Projects)/` | 有截止期的任务 | 会结束 |
| `03-领域(Areas)/` | 长期责任领域：健康、财务、职业… | 不会结束，只需维系 |
| `04-资源(Resources)/` | 模板与参考资料 | 可复用 |
| `05-归档(Archives)/` | 完成或冷冻的内容 | 不再主动维护 |
| `wiki/` | 消化后的知识卡片 + 索引 | 从素材提炼而成 |
| `raw/` | 原始素材（只读） | 未经加工 |
| `assets/` | 图片、附件 | — |

## 建议的第一步

1. 在 `03-领域(Areas)/` 下建一个你自己的领域目录（例如 `健康/`），并写一份 `README.md` 作为该领域的入口页；
2. 在 `03-领域(Areas)/个人/` 下写 3 份档案：基础画像、目标与价值观、财务状况——AI 助理回答规划类问题前会先读它们；
3. 打开 Obsidian 的模板插件设置，把 `04-资源(Resources)/Templates/` 设为模板目录；
4. 每天用日记模板开一篇，写够一周，你就知道这套结构哪里需要改。

## 给 AI 助理看的规范

仓库根目录的 `AGENTS.md` 就是助理的工作规范。改它，等于改助理的行为。
